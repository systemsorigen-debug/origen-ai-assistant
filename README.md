# Origen AI Assistant

A standalone, installable-anywhere Frappe app: a permission-aware, read-only AI analyst chat for Desk.

Supported: Frappe 15.x–16.x. No required dependency on any other app (CRM, ERPNext, Origen Desk Kit, or any
site-specific customization). Every DocType/field/role it knows about the host site is discovered at install
time, never hardcoded.

## What it does

- A chat assistant, reachable from a dedicated Desk Page plus a site-wide navbar shortcut, visible only to users
  holding the `AI Assistant User` role.
- Answers analytics/reporting questions using **live, permission-scoped reads** — every data lookup runs under the
  real logged-in user's own Frappe permissions (`frappe.get_list`, never `ignore_permissions`), so a user who can't
  read a DocType gets no insight from it either.
- **Never writes to a business record.** It has no tool capable of insert/update/delete/submit/cancel or raw SQL
  execution — not disallowed by instruction, disallowed by not existing. When asked "what SQL would answer this,"
  it composes that as plain text for a human to run themselves; it never runs it.
- Keeps an up-to-date, versioned knowledge base of the host site's own schema and automation, generated by a
  re-runnable discovery job — not a single static file that goes stale.

## What it does not do

It will not install, configure, or depend on any specific AI provider's infrastructure beyond holding an API key
you supply in Settings. It will not modify any DocType, Custom Field, Property Setter, Workflow, script, role, or
permission that existed before it was installed — see `AI Assistant Settings` and the project's own plan document
for the full isolation/uninstall guarantees.

## Install

```
bench get-app origen_ai_assistant <git-url>
bench --site <site> install-app origen_ai_assistant
bench build --app origen_ai_assistant
bench --site <site> migrate
```

Then open **AI Assistant Settings** in Desk: pick a provider, paste an API key, enable the app, and run
**Discover Site** once before anyone starts chatting.

## Uninstall

```
bench --site <site> uninstall-app origen_ai_assistant
bench --site <site> migrate
```

Removes only what this app created (its own DocTypes/records, its three Roles and the role-assignments it made,
its scheduled job, its private knowledge file). Nothing that existed before install is touched.
